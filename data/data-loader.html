Data Loader User Guide

The data loader stack is the unified entry point for loading ocean model output and observation data from any source — local NetCDF files, cloud object stores, Copernicus Marine (CMEMS) remote datasets, CMIP6 model output from the PANGEO cloud catalog, and ISIMIP climate forcing data from the ISIMIP repository.

Module layout

Module Role
lib/data_loader.py DataLoader class — universal load_data(), config routing, subsetting
lib/netcdf_loader.py NetCDFLoader — triple-fallback time decoding, glob, singleton squeeze
lib/csv_loader.py CSVLoader — CSV / TSV tabular data, auto-detects time/lat/lon columns
lib/copernicus_loader.py CopernicusLoader — CMEMS remote access via copernicusmarine
lib/cmip6_loader.py CMIP6Loader — PANGEO CMIP6 catalog via intake-esm
lib/isimip_loader.py ISIMIPLoader — ISIMIP repository via REST API / isimip-client
lib/data_utils.py Shared spatial/time helpers used by all loaders
cli/data_loader.py CLI entry point — installed as the data-loader command

lib/ modules are importable as ocean_data.* (an editable install); cli/data_loader.py is the data-loader executable.

DataLoader.load_data() delegates to the specialist loaders automatically: - .nc / glob / directory → NetCDFLoader - .csv / .tsv / .txt → CSVLoader - .zarr / cloud URI → xarray Zarr backend - copernicus:// → CopernicusLoader - cmip6:// → CMIP6Loader - isimip:// → ISIMIPLoader

1. Installation and setup

Core dependencies (always required):

conda activate ocean-stack      # see ocean-stack/environment.yml
Feature Package(s) Notes
CSV / TSV pandas usually already present
Zarr / cloud zarr, s3fs, gcsfs, fsspec only for Zarr stores
Copernicus Marine copernicusmarine + copernicusmarine login
CMIP6 intake, intake-esm, gcsfs PANGEO cloud catalog
ISIMIP (full) isimip-client enables server-side cutout
ISIMIP (basic) requests fallback; usually already present

If an optional package is missing, the relevant feature raises a RuntimeError with install instructions; all other loader features are unaffected.

For Copernicus Marine, credentials must be stored once:

copernicusmarine login    # prompts for CMEMS username/password
                          # credentials stored in ~/.copernicusmarine/

3. Local files and glob patterns

3.1 Single files and directories

# Show file metadata (variables, dimensions, time range, domain)
data-loader /data/model.nc --info

# Load a specific variable and print the xarray summary
data-loader /data/model.nc --variable sst

# Works with directories too (all *.nc concatenated along time)
data-loader /data/model_output/ --variable sst --info

3.2 Glob patterns (multi-file loading)

Pass a glob pattern as the path to load and concatenate multiple files. Quote the pattern to prevent the shell expanding it:

data-loader '/data/CCI-SST/sst_202*.nc' --variable analysed_sst

data-loader '/data/OSTIA/2022/??/*.nc' \
    --variable analysed_sst \
    --domain -5. 15. 50. 65. \
    --output ostia_ns_2022.nc

Supported wildcard characters (Python glob module):

Pattern Meaning Example match
* Any characters (one directory level) sst_202*.nc → sst_2021.nc, sst_2022.nc
? Any single character ??/*.nc → 01/file.nc, 12/file.nc
[0-9] Character range sst_201[0-9].nc → 2010–2019
** Any number of directory levels **/ocean.nc → any subdirectory

Brace expansion {a,b} is a shell feature, not Python glob. For portable multi-pattern loading iterate in Python: python files = sorted(glob('/data/2021/*.nc')) + sorted(glob('/data/2022/*.nc')) ds = xr.open_mfdataset(files, combine='by_coords')

Files are sorted alphabetically before concatenation; standard YYYYMM / YYYYMMDD naming gives chronological order automatically.

Python API:

from ocean_data.data_loader import DataLoader
loader = DataLoader()

ds = loader.load_data('/data/CCI-SST/sst_202*.nc', variable='analysed_sst')

ds = loader.load_data('/data/OSTIA/2022/??/*.nc', variable='analysed_sst',
                      domain={'lon_min': -5, 'lon_max': 15,
                              'lat_min': 50, 'lat_max': 65})

4. Shared CLI options

These options apply to all data-loader calls regardless of the data source.

4.1 --domain lon_min lon_max lat_min lat_max

Four space-separated floats. Both −180..180 and 0..360 longitudes are accepted; values > 180 are automatically normalised to −180..180.

--domain -5. 15. 50. 65.     # -180..180
--domain 355. 15. 50. 65.    # 0..360, same region

Because the shell can mistake a leading - for a flag, place --domain last on the command line, or use trailing-dot floats (-5.).

4.2 --time-range START END

--time-range 2023-01-01 2023-12-31

Passed directly to the remote API for CMEMS / CMIP6 / ISIMIP; applied with xarray time selection for local files.

4.3 --config FILE / --section NAME

Load a named block from a YAML config file instead of specifying all parameters on the command line.

data-loader --config my_experiment.yaml
data-loader --config my_experiment.yaml --section sst_cmems

See YAML config reference for the config format.

4.4 --output FILE

Save the loaded dataset to NetCDF, or metadata to JSON (for --*-describe and --*-catalog commands). The extension is added automatically if omitted (.nc for datasets, .json for metadata).

5. Python API — DataLoader

import sys
sys.path.insert(0, 'lib')   # run from the repo root, or use an absolute path

from ocean_data.data_loader import DataLoader

loader = DataLoader()

lib/ is not a Python package (no __init__.py), so always insert it on sys.path before importing. The python/ scripts do this automatically.

5.1 load_data()

Universal entry point — auto-detects format from the path or routes on URI scheme.

# Local NetCDF
ds = loader.load_data('/data/model.nc', variable='sst')

# Glob pattern
ds = loader.load_data('/data/sst_2023*.nc', variable='analysed_sst')

# Local Zarr
ds = loader.load_data('/data/model.zarr', variable='sst')

# Copernicus Marine via URI
ds = loader.load_data(
    'copernicus://cmems_obs-sst_atl_phy_nrt_l3s_P1D-m',
    variable='sea_surface_temperature',
    domain={'lon_min': -5, 'lon_max': 15, 'lat_min': 50, 'lat_max': 65},
    time_range=('2023-01-01', '2023-01-31'),
)

# CMIP6 via URI
ds = loader.load_data(
    'cmip6://CESM2/historical/tos/Omon/r1i1p1f1',
    domain={'lon_min': -5, 'lon_max': 15, 'lat_min': 50, 'lat_max': 65},
    time_range=('1990-01-01', '1999-12-31'),
)

# ISIMIP via URI
ds = loader.load_data(
    'isimip://ISIMIP3b/MRI-ESM2-0/ssp585/tas',
    domain={'lon_min': -5, 'lon_max': 15, 'lat_min': 50, 'lat_max': 65},
    time_range=('2060-01-01', '2069-12-31'),
)

Key parameters:

Parameter Type Description
path str / Path Local path, cloud URI, or copernicus:// / cmip6:// / isimip:// URI
variable str Single variable to extract (loads all if omitted)
format str 'netcdf', 'zarr', 'copernicus', 'cmip6', 'isimip' (auto-detected)
time_range tuple ('YYYY-MM-DD', 'YYYY-MM-DD') date subsetting
time_slice dict {'start': 0, 'end': 10} index-based subsetting
domain dict {'lon_min', 'lon_max', 'lat_min', 'lat_max'}
chunks dict / 'auto' Dask chunking
storage_options dict Cloud credentials (see Cloud storage)
decode_times bool CF time decoding (default True)

5.2 load_from_config()

Reads a YAML config block and dispatches to the right loader.

import yaml

with open('my_config.yaml') as f:
    config = yaml.safe_load(f)

ds = DataLoader.load_from_config(config)                       # default section
ds = DataLoader.load_from_config(config, section='sst_cmems') # named section

See YAML config reference for the full format.

5.3 load_model_data()

Higher-level helpers for local files with time-range and domain subsetting.

ds = loader.load_model_data(
    '/data/model/output/',
    variable='temp',
    time_range=('2021-01-01', '2021-12-31'),
    domain={'lon_min': -10, 'lon_max': 5, 'lat_min': 50, 'lat_max': 60},
)

The path may be a file, a glob pattern or a directory (files named after the variable are preferred). Variable names and dimensions are kept as in the file; variable is resolved through the name aliases, and a variable that is not there raises ValueError. With chunks= (e.g. {'time': 30}) the result is dask-backed, otherwise numpy-backed; both hold the same data.

Module-level convenience functions (no need to instantiate DataLoader):

from ocean_data.data_loader import load_model_data, get_file_info

ds   = load_model_data('/data/model.nc', variable='sst')
info = get_file_info('/data/model.nc')

5.4 Cache (cache_dir)

CMIP6 (cmip6://, pangeo://) and Copernicus Marine fetches are saved in cache_dir. A request is served from a cached file when either

  • its exact request (source, variables, domain, time range, depth range) was cached before, or
  • a cached file has the same source id (including member, table, frequency and grid), the same variables and the same depth range, and its time range and domain cover the request (32-day and 0.5-degree tolerance).

The identity for the second case is stored in the file's global attribute ocean_data_cache_identity. Files cached before that attribute existed serve exact requests only.

7. Longitude conventions

All domain dicts are stored internally in −180..180. The data's convention is detected automatically at subsetting time and the domain is converted to match — no manual conversion is needed.

User input Data convention Result
−180..180 −180..180 direct
−180..180 0..360 converted automatically
0..360 0..360 converted automatically
0..360 −180..180 converted automatically

Wrap-around domains (e.g. lon_min=350, lon_max=10 crossing the dateline) are handled with an OR mask so no data is missed at the seam.

CLI: values > 180 are normalised when parsed:

--domain 345. 15. 50. 65.    # 345 → -15, result: lon -15..15 lat 50..65

8. Coordinate name handling

CoordinateMapper (from lib/name_mappings.py, configured in config/name_mappings.yaml) resolves non-standard coordinate names automatically. You never need to hard-code ds['nav_lat'] or similar.

Coordinate Known aliases
latitude lat, latitude, latt, nav_lat, TLAT, lat_rho, ylat
longitude lon, longitude, lont, nav_lon, TLONG, lon_rho, xlon
time time, ocean_time, valid_time, mt, t
depth depth, z, lev, level, s_rho

To add support for a new model format, add its coordinate names to config/name_mappings.yaml — no Python changes needed.

9. NetCDF loading details

Time decoding

A triple-fallback strategy handles difficult files:

  1. Standard xarray decode_times=True — works for most files
  2. cftime use_cftime=True — handles proleptic_gregorian and other non-standard calendars
  3. Manual decode via netCDF4.num2date — handles masked fill values in the time coordinate, files with broken _FillValue, etc.

If all three fail, a sequential integer index replaces the time coordinate and a warning is logged. Use lib/time_fix_helper.py for detailed diagnostics.

ds = loader.load_data('/data/model.nc', decode_times=False)  # skip decoding

Singleton dimensions

Non-essential dimensions of size 1 are silently squeezed and dropped. The most common case is SSS stored with a depth=1 dimension:

# Before loading                      # After loading
Dimensions: (time, depth, lat, lon)   →   Dimensions: (time, lat, lon)
            depth=1

lat, lon, and time are never squeezed. All other size-1 dimensions (depth, lev, level, z, s_rho, …) are removed automatically.

10. Cloud storage

All cloud paths are routed through xarray's Zarr backend.

# Amazon S3 — public bucket
ds = loader.load_data('s3://bucket/ocean.zarr', storage_options={'anon': True})

# Amazon S3 — private bucket
ds = loader.load_data('s3://bucket/ocean.zarr', storage_options={
    'key': 'ACCESS_KEY', 'secret': 'SECRET_KEY',
})

# Google Cloud Storage — public
ds = loader.load_data('gs://bucket/ocean.zarr', storage_options={'token': 'anon'})

# Google Cloud Storage — authenticated
ds = loader.load_data('gs://bucket/ocean.zarr', storage_options={
    'token': '/path/to/service_account.json',
})

# Azure Blob Storage
ds = loader.load_data('az://container/ocean.zarr', storage_options={
    'account_name': 'myaccount', 'account_key': 'mykey',
})

11. Copernicus Marine (CMEMS)

CopernicusLoader opens Copernicus Marine (CMEMS) datasets via the copernicusmarine package. All data is streamed directly from the remote ARCO/Zarr store; nothing is downloaded unless you explicitly save to NetCDF.

11.1 Installation

pip install copernicusmarine
copernicusmarine login    # stores credentials in ~/.copernicusmarine/

11.2 URI scheme

copernicus://DATASET_ID

Example:

copernicus://cmems_obs-sst_atl_phy_nrt_l3s_P1D-m

11.3 Describe a dataset

Inspect variables, spatial extent, and time range without downloading data.

data-loader --cmems-describe cmems_obs-sst_atl_phy_nrt_l3s_P1D-m

data-loader --cmems-describe cmems_obs-sst_atl_phy_nrt_l3s_P1D-m \
    --output sst_meta.json

Output fields:

Key Content
dataset_id The dataset identifier
variables List of variable short names
variable_details units, long_name per variable
dimensions Dimension sizes
domain lon_min, lat_min, lon_max, lat_max
time_range start, end, n_steps

Two describe strategies: copernicusmarine.describe() (fast, no data transfer) is tried first. If it fails, a lazy open_dataset() is used as fallback and also provides dimension sizes and time range.

11.4 Browse the catalogue

# Full CMEMS catalogue to JSON (~10–20 MB, ~10 s)
data-loader --cmems-catalog --output cmems_catalog.json

# Filter by keyword (much faster)
data-loader --cmems-catalog --contains SST NRT Atlantic \
    --output cmems_sst_nrt_atl.json

# List all dataset IDs with jq
data-loader --cmems-catalog --contains SST \
    | jq -r '.products[].datasets[].dataset_id'

Save the catalogue JSON once, then search it offline with jq or Python.

11.5 Load data

data-loader \
    --copernicus cmems_obs-sst_atl_phy_nrt_l3s_P1D-m \
    --variable sea_surface_temperature \
    --domain -5. 15. 50. 65. \
    --time-range 2023-01-01 2023-01-31 \
    --output sst_jan2023.nc

11.6 Python API

from ocean_data.copernicus_loader import CopernicusLoader

loader = CopernicusLoader()

# Describe
info = loader.describe('cmems_obs-sst_atl_phy_nrt_l3s_P1D-m')
print(info['variables'])    # ['sea_surface_temperature', …]
print(info['time_range'])   # {'start': '…', 'end': '…', 'n_steps': …}

# Browse catalogue
catalog = loader.fetch_catalog(contains=['SST', 'NRT'])
for product in catalog['products']:
    for ds in product.get('datasets', []):
        print(ds['dataset_id'])

# Load
ds = loader.load(
    'cmems_obs-sst_atl_phy_nrt_l3s_P1D-m',
    variables=['sea_surface_temperature'],
    domain={'lon_min': -5, 'lon_max': 15, 'lat_min': 50, 'lat_max': 65},
    time_range=('2023-01-01', '2023-01-31'),
)

Via DataLoader:

from ocean_data.data_loader import DataLoader

loader = DataLoader()
ds = loader.load_data(
    'copernicus://cmems_obs-sst_atl_phy_nrt_l3s_P1D-m',
    variable='sea_surface_temperature',
    domain={'lon_min': -5, 'lon_max': 15, 'lat_min': 50, 'lat_max': 65},
    time_range=('2023-01-01', '2023-01-31'),
)

# DataLoader also exposes thin wrappers for convenience:
info    = loader.describe_copernicus_dataset('cmems_obs-sst_atl_phy_nrt_l3s_P1D-m')
catalog = loader.fetch_copernicus_catalog(contains=['SST'])

11.7 NRT vs reanalysis datasets

CMEMS datasets fall into two categories with different time coverage:

Dataset tag Type Time coverage
_nrt_, _mynrt_ Near-real-time Rolling window (~1–2 years)
_my_, _rep_ Reanalysis / hindcast Fixed multi-decade archive

Requesting a time_range outside the available window causes a mismatch error. Always check first with --cmems-describe.

11.8 Tips

  • Describe before loading — verify variable names and available dates.
  • WARNING: Connection pool is full — benign urllib3 warning from parallel chunk fetching. Suppress with warnings.filterwarnings('ignore', message='Connection pool is full'), or reduce concurrency by passing larger chunks.

12. CMIP6 (PANGEO / intake-esm)

CMIP6Loader opens CMIP6 model output directly from Google Cloud Storage via the PANGEO intake-esm catalog — no manual downloads required.

12.1 Installation

pip install intake intake-esm gcsfs

12.2 URI scheme

cmip6://SOURCE_ID/EXPERIMENT_ID/VARIABLE_ID/TABLE_ID/MEMBER_ID[/GRID_LABEL]

Examples:

cmip6://CESM2/historical/tos/Omon/r1i1p1f1
cmip6://UKESM1-0-LL/ssp585/tos/Omon/r1i1p1f2/gn

table_id quick reference:

table_id Frequency Realm Example variables
Omon Monthly Ocean tos, sos, zos, thetao, so
Oday Daily Ocean tos
Amon Monthly Atmosphere tas, pr, ua
SImon Monthly Sea ice siconc, sithick

grid_label: gn (native, most common) or gr (regridded).

12.3 Describe available datasets

Dataset discovery (--cmip6-describe/--cmip6-catalog in older versions) now queries the ESGF search index rather than downloading the PANGEO catalog, via --esgf-describe. All filters are optional — each one narrows the search:

# Show all available members, grids, and experiments for a model + variable
data-loader --esgf-describe --source-id CESM2 --variable-id tos

# Filter further
data-loader --esgf-describe \
    --source-id CESM2 --experiment historical --variable-id tos --table Omon \
    --output cesm2_describe.json

# Use a different ESGF index node (default: LLNL)
data-loader --esgf-describe --source-id CESM2 --node-url https://esgf-data.dkrz.de/esg-search

The result is a dict of n_datasets, source_ids, experiment_ids, variable_ids, table_ids, member_ids, grid_labels — saved as JSON with --output, or printed.

12.4 Browse without filters

There is no dedicated "download the whole catalog" flag anymore — ESGF is a live search index, not a static catalog file. Omitting every filter still works (--esgf-describe with nothing else), but searches the entire CMIP6 archive, so it is slow and rarely what you want; narrow with at least --source-id or --variable-id first.

12.5 Load data

data-loader \
    --cmip6 CESM2/historical/tos/Omon/r1i1p1f1 \
    --domain -5. 15. 50. 65. \
    --time-range 1990-01-01 1990-12-31 \
    --output cesm2_tos_1990.nc

12.6 Python API

CMIP6Loader (below) talks to the PANGEO intake-esm catalog directly — a different backend from --esgf-describe/--cmip6 on the CLI, which search ESGF (falling back to PANGEO only for --cmip6 loads, not for --esgf-describe). Use CMIP6Loader directly when you specifically want the PANGEO catalog's own describe/fetch_catalog.

from ocean_data.cmip6_loader import CMIP6Loader

loader = CMIP6Loader()

# Describe
info = loader.describe(
    source_id='UKESM1-0-LL',
    experiment_id='ssp585',
    variable_id='tos',
)
print(info['member_ids'])   # ['r1i1p1f2', 'r2i1p1f2', …]
print(info['n_datasets'])

# Browse catalogue
records = loader.fetch_catalog()   # list of dicts, one per store

# Load
ds = loader.load(
    source_id='CESM2',
    experiment_id='historical',
    variable_id='tos',
    table_id='Omon',
    member_id='r1i1p1f1',
    grid_label='gn',
    domain={'lon_min': -5, 'lon_max': 15, 'lat_min': 50, 'lat_max': 65},
    time_range=('1990-01-01', '1999-12-31'),
)

Via DataLoader:

from ocean_data.data_loader import DataLoader

loader = DataLoader()
ds = loader.load_data(
    'cmip6://CESM2/historical/tos/Omon/r1i1p1f1',
    domain={'lon_min': -5, 'lon_max': 15, 'lat_min': 50, 'lat_max': 65},
    time_range=('1990-01-01', '1999-12-31'),
)

Via DataLoader.load_from_config():

config = {
    'source': 'cmip6',
    'source_id': 'CESM2',
    'experiment_id': 'historical',
    'variable_id': 'tos',
    'table_id': 'Omon',
    'member_id': 'r1i1p1f1',
    'domain': {'lon_min': -5, 'lon_max': 15, 'lat_min': 50, 'lat_max': 65},
    'time_range': ['1990-01-01', '1999-12-31'],
}
ds = DataLoader.load_from_config({'observations': config})

12.7 Tips

  • Find member IDs first with --esgf-describe — not every model provides r1i1p1f1.
  • Temperature: tos and thetao are automatically converted from Kelvin to Celsius when the dataset's units attribute is 'K'.
  • Chunking: CMIP6 Zarr stores are already chunked; chunks='auto' (the default) lets Dask align boundaries automatically.
  • Multiple matches: if more than one dataset matches your facets, a warning lists all matches and the first is used. Narrow the search with grid_label or a specific member_id.

13. ISIMIP climate forcing data

ISIMIPLoader accesses ISIMIP bias-adjusted atmospheric forcing data — the standard input for ocean, hydrological, and impact models under the ISIMIP protocol.

13.1 Installation

pip install isimip-client   # enables server-side cutout — strongly recommended

isimip-client is optional; requests (fallback) is usually already present. No login is required for most datasets (CC0 open access).

13.2 Simulation rounds and variables

13.7 Cutout service

When cutout=True (default) and isimip-client is installed, loading with a domain follows this sequence:

  1. Files matching the query are found via the ISIMIP REST API.
  2. A bounding-box cutout job is submitted to https://files.isimip.org/api/v2/.
  3. The loader polls every 4 seconds until the job is done.
  4. The resulting NetCDF is downloaded to cache_dir (if set) and reused on subsequent calls.

When cutout=False or isimip-client is not installed, full decade files are downloaded to cache_dir and domain subsetting is applied locally.

# Force full download (e.g. when cutout service is slow)
ds = loader.load(..., cutout=False)

13.8 Tips

  • Forcing names are case-sensitive: use W5E5, GSWP3-W5E5, MRI-ESM2-0 exactly. Use --isimip-describe to see what's available.
  • Temperature: tas is automatically converted from Kelvin to °C.
  • Multi-decade loads: pass the full time range — the loader automatically identifies and concatenates all relevant decade files.
  • Bias correction: see python/bias_correct_forcings.py and config/bc_correct_example.yaml for correcting ISIMIP3b projections against ERA5 / W5E5 observations.

14. CSV / TSV data

CSVLoader loads tabular observation data — station time series, along-track satellite files, pre-processed validation tables — into xr.Dataset with time as the primary dimension. DataLoader.load_data() routes to it automatically for .csv, .tsv, and .txt extensions.

14.1 Installation

pip install pandas   # usually already present in the conda environment

14.2 Column detection

The loader searches column names case-insensitively:

Coordinate Recognised names (priority order)
time time, date, datetime, timestamp, t
latitude lat, latitude, latt, nav_lat, ylat
longitude lon, longitude, lont, nav_lon, xlon

Delimiter is auto-detected (tab for .tsv or lines containing \t; semicolon for lines containing ;; otherwise comma).

Pass explicit names to the constructor to override detection:

from ocean_data.csv_loader import CSVLoader
loader = CSVLoader(time_col='obs_time', lat_col='LAT', lon_col='LON')

15. Troubleshooting

copernicusmarine not found

RuntimeError: copernicusmarine package is required …

Install: pip install copernicusmarine then copernicusmarine login.

CMEMS time range mismatch / empty result

The requested dates fall outside the dataset's available window. Use --cmems-describe to inspect available dates, or switch to a reanalysis dataset (see NRT vs reanalysis).

WARNING: Connection pool is full (CMEMS)

Benign urllib3 warning from parallel chunk fetching. Suppress with:

import warnings
warnings.filterwarnings('ignore', message='Connection pool is full')

Or pass larger chunks to reduce concurrency.

intake/intake-esm not found (CMIP6)

RuntimeError: intake and/or intake-esm are not installed …

Install: pip install intake intake-esm gcsfs.

CMIP6: no datasets found

Check spelling with --esgf-describe. If multiple members exist but r1i1p1f1 is missing, use describe() to list available member_ids.

ISIMIP: no files found

RuntimeError: No ISIMIP files found for ISIMIP3b/mri-esm2-0/ssp585/tas.

Forcing names are case-sensitive. Use --isimip-describe to see exact spelling. Common names: W5E5, GSWP3-W5E5, MRI-ESM2-0, UKESM1-0-LL, GFDL-ESM4, IPSL-CM6A-LR, MPI-ESM1-2-HR.

ISIMIP: cutout job did not complete

RuntimeError: ISIMIP cutout job did not complete (status='started').

The cutout service is occasionally slow for large requests. Pass cutout=False to fall back to full download + local subset.

ISIMIP: isimip-client not installed

The requests fallback is used automatically, but the cutout service is unavailable — full global files (~860 MB each) are downloaded instead. Install isimip-client to enable server-side subsetting.

Coordinate not found / subsetting skipped

The file uses an unusual coordinate name. Add it to config/name_mappings.yaml under the appropriate alias list. Check what the file contains:

data-loader /data/model.nc --info

Time axis replaced with integer index

The original time coordinate had masked or invalid values. A warning is logged. Use lib/time_fix_helper.py for detailed diagnostics.

Zarr consolidated metadata error

ds = loader.load_data('path/to/store.zarr', consolidated=False)
