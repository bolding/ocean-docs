ocean-data

Data loading and coordinate utilities for ocean model data. Provides a unified DataLoader that transparently handles local NetCDF/Zarr files, Copernicus Marine (CMEMS), CMIP6 (Pangeo / ESGF), Argo, ICES, GLODAP, WOD, EMODnet, and ERA5 cloud archives behind a single interface. A CoordinateMapper resolves the 20+ naming conventions used by different models and reanalysis products so the rest of your code never hard-codes "lat" vs "latitude" vs "nav_lat".

For the full ocean-* toolkit, install via ocean-stack rather than this package alone. ocean-stack sets up all four packages in a single conda environment — the recommended route because xesmf/esmpy, used for regridding in ocean-data and ocean-prep, must come from conda-forge and cannot be reliably pip-installed. Use the standalone installation below only if you need this package in isolation.

Part of the ocean-* family: ocean-data · ocean-plot · ocean-prep · ocean-post

Installation

pip install -e .

Optional extras install the backends for each remote source:

pip install -e ".[copernicus]"   # copernicusmarine
pip install -e ".[pangeo]"       # intake-esm + gcsfs  (CMIP6 via Pangeo)
pip install -e ".[esgf]"         # intake-esgf + esgf-pyclient (CMIP6 via ESGF)
pip install -e ".[era5gcs]"      # gcsfs + zarr  (ERA5 on Google Cloud)

Quick start

from ocean_data.data_loader import DataLoader
from ocean_data.name_mappings import CoordinateMapper

loader = DataLoader()

# Local file
ds = loader.load_data('/data/model.nc', 'temperature')

# CMEMS Copernicus Marine
ds = loader.load_data(
    'copernicus://cmems_mod_glo_phy-thetao_anfc_0.083deg_P1D-m',
    variable='thetao',
    domain={'lon_min': -5, 'lon_max': 15, 'lat_min': 50, 'lat_max': 65},
    time_range=('2023-01-01', '2023-01-31'),
)

# CMIP6 via Pangeo
ds = loader.load_data(
    'cmip6://MPI-ESM1-2-HR/historical/tos/Omon/r1i1p1f1',
    domain={'lon_min': -5, 'lon_max': 15, 'lat_min': 50, 'lat_max': 65},
)

# Coordinate-agnostic access
mapper = CoordinateMapper()
lat_name = mapper.find_coordinate(ds, 'latitude')   # returns 'nav_lat', 'latt', 'lat', etc.

# Inspect a local file or download from any source
data-loader /data/model.nc --info
data-loader --copernicus cmems_obs-sst_atl_phy_nrt_l3s_P1D-m \
    --variable sea_surface_temperature --domain -5 15 50 65 \
    --time-range 2023-01-01 2023-01-31 --output sst.nc

    --domain -5 15 50 65 --time-range 1990-01-01 1990-12-31 --output cesm2.nc

CoordinateMapper

CoordinateMapper reads config/name_mappings.yaml and resolves coordinate names across all common model and reanalysis conventions:

from ocean_data.name_mappings import CoordinateMapper

mapper = CoordinateMapper()
lat  = mapper.find_coordinate(da, 'latitude')    # 'latt', 'nav_lat', 'lat', …
lon  = mapper.find_coordinate(da, 'longitude')
time = mapper.find_time_dimension(da)

Supported models out of the box: pyGETM (latt/lont), NEMO (nav_lat/nav_lon), ROMS (lat_rho/lon_rho), CESM (TLAT/TLONG), ERA5 (latitude/longitude), standard CF (lat/lon). Adding a new model = add aliases to config/name_mappings.yaml; no Python changes needed.
