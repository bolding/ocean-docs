Single-environment setup for the full ocean-* package family:

Package Role
ocean-common Small shared helpers (e.g. ocean_common.progress), no heavy deps
ocean-data Data loading, coordinate normalisation (CoordinateMapper), CMEMS coverage, xESMF regridding
ocean-plot Cartopy maps, animations, YAML-driven plot configs
ocean-prep Input preparation — bathymetry, boundary conditions, initial conditions, bias correction of CMIP6 forcing
ocean-post Model validation, scenario analysis, and statistical reporting

This repo contains no package code — environment files (environment.yml, environment-windows.yml) that install all five packages in editable mode, so changes to any repo are immediately visible without reinstalling, plus the update scripts and check_doc_consistency.py. The key reason for a shared environment is that xesmf/esmpy — used by ocean-data for obs→model regridding and by ocean-prep for bathymetry regridding and bias correction — must come from conda-forge and cannot be reliably pip-installed. On Windows, esmpy is stuck at 8.4.0 and incompatible with current xesmf; use environment-windows.yml instead — regridding operations fall back to scipy.interpolate. Use the individual repos directly only if you need a single package in isolation.

ocean-common · ocean-data · ocean-plot · ocean-prep · ocean-post

Setup

1. Clone all repos as siblings:

git clone git@github.com:bolding/ocean-common ocean-common
git clone git@github.com:bolding/ocean-data  ocean-data
git clone git@github.com:bolding/ocean-plot  ocean-plot
git clone git@github.com:bolding/ocean-prep  ocean-prep
git clone git@github.com:bolding/ocean-post ocean-post
git clone git@github.com:bolding/ocean-stack ocean-stack

2. Create and activate the conda environment:

cd ocean-stack

# Linux / macOS
conda env create -f environment.yml

# Windows (xesmf unavailable — regridding falls back to scipy)
conda env create -f environment-windows.yml

conda activate ocean-stack

All five packages are installed in editable mode (pip install -e), so changes to any repo are immediately visible without reinstalling.

3. Verify:

python -c "import ocean_common, ocean_data, ocean_plot, ocean_prep, ocean_post; print('ok')"
bathymetry-regrid --help
run-cmems-boundaries --help

# Run all test suites
for pkg in ocean-common ocean-data ocean-plot ocean-prep ocean-post; do
    pytest ../$pkg
done

Updating

Use the provided scripts — they pull all five repos, update the conda environment if the environment file changed, verify each package is installed (and pip install -e any that are missing), then run the full test suite:

# Linux / macOS (activate ocean-stack first)
./update-and-test.sh

# Windows
update-and-test.bat
