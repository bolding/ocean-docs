ocean-* documentation

Tools for preparing, validating and analysing regional ocean model runs.

From data to results

The ocean-* packages cover the steps around a regional ocean model run: getting the data, preparing the model input, and validating and analysing the results. Each step is a set of command-line tools driven by YAML configuration files, with a Python API underneath. The packages are model-agnostic; the examples come from pyGETM setups for the North Sea and the Baltic.
