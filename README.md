# ocean-* documentation

Documentation of the ocean-* packages (ocean-data, ocean-prep, ocean-post, ocean-plot,
ocean-common), published with GitHub Pages: **https://bolding.github.io/ocean-docs/**

The packages cover the steps around a regional ocean model run: getting the data,
preparing the model input, and validating and analysing the results.

This repository holds only the generated site. The pages are built from the guides in
the package repositories (not public yet) with `ocean-stack/tools/web/site.py`, so edits
made here directly are overwritten.
