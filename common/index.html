ocean-common

Small, dependency-light utilities shared across the ocean-* family (ocean-plot, ocean-post, ocean-prep, ocean-data, ...). Created 2026-10-24 out of the cross-repo code review, which found the same tty-aware tqdm wrapper reimplemented independently at least 9 times across three repos.

Deliberately kept separate from ocean-data (a data-loader library with its own stated scope) rather than mixed into it, so this stays the obvious home for any future shared, generic utility too -- not just this one.

Install

pip install -e .
# or, to guarantee tqdm is present (progress_iter works fine without it too):
pip install -e ".[progress]"

Modules

  • ocean_common.progress -- progress_iter(iterable, **tqdm_kwargs): wraps an iterable in tqdm when it's installed and stderr is a real terminal, otherwise returns it unchanged. show_progress() gives the same condition for callers that drive their own tqdm object; HAS_TQDM tells whether tqdm is installed.

  • ocean_common.progress.progress_bar(total, desc) -- a manually updated bar (.update(n), .close(), with): tqdm, or a no-op object.

  • ocean_common.log.setup_logging(verbose) -- the root-logger setup used by every CLI (HH:MM:SS LEVEL message).
  • ocean_common.config.deep_merge(base, override) -- recursive dict merge.
  • ocean_common.version.get_version(dist_name, package_file) -- installed version, else git:<hash> of the checkout.
