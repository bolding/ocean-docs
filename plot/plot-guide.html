Static Plot Guide

ocean-plot renders a single map frame from a NetCDF variable and saves it as a PNG (or any matplotlib-supported format). It uses the same Cartopy rendering pipeline as ocean-animations, so coastlines, land fill, and gridlines are included automatically when Cartopy is installed.

Quick start — init-plot wizard

init-plot
# → prompts for file, variable, time selection, subset, DPI
# → writes e.g. sst_plot.yaml

ocean-plot --config sst_plot.yaml
ocean-plot --config sst_plot.yaml --show    # open in viewer after saving

Config format

Full documented template: examples/plot_map.yaml.

plottype: map          # 'map' (single frame) or 'map_mean' (time average)

input:
  file: /data/ERA5/NA/era5_t2m_2019.nc
  variable: t2m
  # time_slice:        # optional: restrict frames before the time selection
  #   start: 0
  #   end: 90

# time_index: 30       # integer frame, 'mean', or omit for first frame
                       # also settable via --time-index on the command line

subset:                # optional — omit for the full domain
  lat_min: 48.0
  lat_max: 65.0
  lon_min: -12.0
  lon_max: 12.0

output:
  # file: t2m_plot.png  # omit → <variable>_plot.png
  dpi: 150

# title:     # omit → auto from long_name / standard_name
# colormap:  # omit → auto from variable metadata
# vmin:      # omit → data range
# vmax:

Time selection

Setting Behaviour
time_index: 30 Frame at index 30 (0-based)
time_index: mean Mean over all loaded frames
plottype: map_mean Equivalent to time_index: mean
omit both First frame (index 0)

Combined with input.time_slice, you can average over a specific sub-range:

input:
  time_slice:
    start: 0
    end: 90      # first 90 frames only
time_index: mean  # mean over those 90 frames

Annotations

All five annotation types are supported; see the Animations guide for the full syntax. time_on / time_off are accepted but silently ignored (all annotations are always drawn in static plots).

annotations:
  - type: text
    lat: 57.0
    lon: 4.0
    text: "North Sea"
    fontsize: 11
    color: white
    ha: center
  - type: point
    lat: 54.5
    lon: 6.0
    marker: "*"
    color: red
    label: "Station A"
  - type: box
    lat_min: 54.0
    lat_max: 58.0
    lon_min: 3.0
    lon_max: 7.0
    color: yellow

Styling

matplotlib loads matplotlibrc from ~/.config/matplotlib/matplotlibrc and from the current working directory automatically. Use style: to select a named style or .mplstyle file for a single run:

style: seaborn-v0_8-paper

See the Animations guide for more detail.

CLI reference

ocean-plot --config plot.yaml                # render and save
ocean-plot --config plot.yaml --show         # open in viewer after saving
ocean-plot --config plot.yaml --time-index 30
ocean-plot --config plot.yaml --time-index mean
ocean-plot --config plot.yaml --output my_plot.png   # override output path
ocean-plot --info /data/model.nc             # list variables, dimensions, and coordinates

--info prints the file dimensions, all coordinate variables (with units and long name), and all data variables — useful for discovering dimension names, depth levels, and time ranges before writing a config.

Flag Description
--config FILE YAML configuration (required unless --info)
--info FILE Describe variables, coordinates and dimensions in a NetCDF file and exit
--show Open the saved plot in an interactive viewer
--output FILE Override output.file from the config
--time-index N\|mean Override time_index from the config
