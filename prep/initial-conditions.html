Initial Conditions Guide

Overview

Downloads temperature and salinity from CMEMS and saves 12 monthly snapshots (1st of each month) on the source model's native grid, clipped to the model domain bounding box.

Requires the [cmems] extra:

pip install -e ".[cmems]"
copernicusmarine login

Config structure

# config/mymodel_init_create.yaml

setup:
  name: mymodel

domain:
  lon_min: -8.0
  lon_max:  13.0
  lat_min:  47.5
  lat_max:  62.0

flood_fill: true    # add {variable}_ff alongside original variable

processing:
  bbox_buffer: 0.1
  download_cache_dir: "/data/cache/cmems/ic"   # null to disable

output:
  base_directory: "./init_data/mymodel"
  filename_template: "{source}_{variable}_{year}_monthly_ic.nc"

sources:
  AMM7:
    year: 2015   # default; override with --year
    datasets:
      temperature:
        sources:
          - dataset_id: "cmems_mod_nws_phy-t_my_7km-3D_P1D-m"
            priority: 1
        variables:
          - name: thetao
        depth_range:
          minimum: 0.0
          maximum: 5000.0
      salinity:
        sources:
          - dataset_id: "cmems_mod_nws_phy-s_my_7km-3D_P1D-m"
            priority: 1
        variables:
          - name: so
        depth_range:
          minimum: 0.0
          maximum: 5000.0

Multiple sources with priority

When several sources entries are listed under a dataset, higher priority values fill in where lower-priority data is masked (e.g. a primary NWS product + a Baltic product to fill the Kattegat halo):

sources:
  - dataset_id: "cmems_mod_nws_phy-t_my_7km-3D_P1D-m"   # primary
    priority: 1
  - dataset_id: "cmems_mod_bal_phy_my_P1D-m"             # fills masked halo
    priority: 0

Workflow

1. Check coverage

download-init-conditions --config config/mymodel_init_create.yaml --source AMM7 --check-coverage

Checks each dataset's spatial extent against the domain bounding box.

2. Dry run

download-init-conditions --config config/mymodel_init_create.yaml --source AMM7 --dryrun

Prints resolved source, year, output paths — no download.

3. Download

download-init-conditions --config config/mymodel_init_create.yaml --source AMM7
download-init-conditions --config config/mymodel_init_create.yaml --source AMM7 --year 2015
download-init-conditions --config config/mymodel_init_create.yaml --source AMM15 --year 2026
Option Description
--source NAME Source key from the config (e.g. AMM7, AMM15)
--year YEAR Override the default year in the config
--check-coverage Coverage check only, no download
--dryrun Print resolved paths, no download

Output

One file per variable:

init_data/mymodel/AMM7_temperature_2015_monthly_ic.nc
init_data/mymodel/AMM7_salinity_2015_monthly_ic.nc

Each file contains 12 time steps (Jan–Dec, day 1 of each month) plus a flood-filled *_ff variable if flood_fill: true.
