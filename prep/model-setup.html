Model Setup Guide

Overview

Setting up a new regional ocean model involves three independent pipelines, each driven by a YAML config file:

init-bathymetry          →  config/<model>_bathy_create.yaml
init-boundaries          →  config/<model>_bdy_create.yaml
init-initial-conditions  →  config/<model>_init_create.yaml

The wizard CLIs prompt for all required values and write the config file. Once you have configs, the run CLIs execute the actual work.

Directory layout

mymodel/
  config/
    mymodel_bathy_create.yaml   # bathymetry regrid config
    mymodel_bdy_create.yaml     # boundary conditions config
    mymodel_init_create.yaml    # initial conditions config
  bdy_coords/
    mymodel_bdy_lonlat.txt      # open boundary point coordinates (lon lat)

Step 1 — Create configs interactively

Run from the model directory (or pass --output to control the file path):

init-bathymetry           --output config/mymodel_bathy_create.yaml
init-boundaries           --output config/mymodel_bdy_create.yaml
init-initial-conditions   --output config/mymodel_init_create.yaml

Step 2 — Bathymetry

Check what the pipeline will do, then run it:

bathymetry-regrid --config config/mymodel_bathy_create.yaml --dryrun
bathymetry-regrid --config config/mymodel_bathy_create.yaml

See bathymetry.md for full details.

Step 3 — Boundary conditions

Check CMEMS dataset coverage before downloading:

check-cmems-coverage --config config/mymodel_bdy_create.yaml
run-cmems-boundaries --config config/mymodel_bdy_create.yaml --dryrun
run-cmems-boundaries --config config/mymodel_bdy_create.yaml

See boundaries-cmems.md or boundaries-cmip6.md.

Step 4 — Initial conditions

download-init-conditions --config config/mymodel_init_create.yaml --source AMM7 --check-coverage
download-init-conditions --config config/mymodel_init_create.yaml --source AMM7

See initial-conditions.md.

Step 5 — QC diagnostics

After boundaries are produced, run diagnostics to check for NaN cells, coverage gaps, and stitching seams:

boundary-diagnostics --output-dir ./boundary_data/mymodel --config config/mymodel_bdy_create.yaml

See boundary-diagnostics.md.

Package dependencies

Extra Enables
(none) Wizards only
[xesmf] Bathymetry regridding (requires conda: esmpy, rioxarray)
[cmems] CMEMS boundary + IC download
[cmip6] CMIP6 boundary download
[plot] Map plots in reports 
pip install -e ".[cmems,xesmf,plot]"
