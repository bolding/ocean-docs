Boundary Diagnostics Guide

Overview

Reads boundary condition NetCDF files (from run-cmems-boundaries, run-cmip6-boundaries, run-tidal-boundaries, or run-delta-boundaries) and produces a set of QC plots and a Markdown report.

Output file Content
map_<dataset>.png Boundary points map coloured by segment, NaN points flagged red
timeseries_<dataset>.png Segment-mean surface (solid) and bottom (dashed) time series
hovmoller_<dataset>.png Hovmöller diagram along the full boundary
profiles_<dataset>.png Mean depth profiles per segment (3-D variables only)
seams_<dataset>.png Stitching-seam zoom plots (--check-seams only)
REPORT.md Markdown summary linking all plots

The surface/bottom time series plot shows two lines per segment: the surface value (solid) and the segment-mean bottom value (dashed). The bottom depth is determined per-boundary-point as the last depth level that is non-NaN at all time steps — each point's geographic seafloor depth.

Usage

Standard run

Point at the directory that contains the boundary NetCDF output files:

boundary-diagnostics --output-dir ./boundary_data/mymodel

Passing --config adds transition dates to the time-series plots (vertical lines where datasets are stitched):

boundary-diagnostics \
    --output-dir ./boundary_data/mymodel \
    --config config/mymodel_bdy_create.yaml

Seam check

After stitching multiple sources in time, verify that the join is smooth:

boundary-diagnostics --output-dir ./boundary_data/mymodel --check-seams

Produces a seams_<dataset>.png per variable zoomed to ±30 days around each transition date.

Multiple output directories (combined report)

When you have hourly and daily boundary files in separate directories, combine them into a single report with per-directory plot prefixes:

boundary-diagnostics \
    --output-dir ./boundary_data/mymodel/hourly \
                 ./boundary_data/mymodel/daily \
    --labels 1h 1d \
    --diag-dir ./boundary_data/mymodel/diagnostics

One REPORT.md is written with a section per directory. The boundary-point map is generated once (from the first directory) since the spatial layout is shared.

Restrict to specific datasets

boundary-diagnostics --output-dir ./boundary_data/mymodel --dataset temperature salinity

Custom output directory

By default, plots are written to <output-dir>/diagnostics/. Override with --diag-dir:

boundary-diagnostics \
    --output-dir ./boundary_data/mymodel \
    --diag-dir   ./qc/mymodel

Options

Option Description
--output-dir DIR [DIR …] One or more directories containing boundary NetCDF files
--labels LABEL [LABEL …] Plot prefix labels for each directory (multi-dir mode)
--config FILE YAML config that generated the boundaries (for transition dates)
--dataset KEY … Process only these dataset keys
--diag-dir DIR Override diagnostic output directory
--check-seams Generate seam-zoom plots around transition dates
--animate-hovmoller Generate animated cross-section MP4 files

What to look for

Map plot — all boundary segments should be coloured; red × markers indicate NaN values.
Any NaN points that persist in the final output will need a segment override or a different source.

Time series — check for sudden jumps at stitching transition dates. Use --check-seams to zoom in. The dashed bottom line should follow a similar seasonal cycle to the surface but with reduced amplitude; a flat line may indicate the bottom depth is only one level.

Hovmöller — reveals persistent missing data (vertical stripes) or suspicious features propagating along the boundary.

Depth profiles — confirm plausible temperature/salinity structure; flat profiles can indicate bad interpolation or a masked level.
