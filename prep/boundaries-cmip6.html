CMIP6 Boundary Conditions Guide

Overview

Extracts boundary conditions from CMIP6 model output (via Pangeo GCS or ESGF) and interpolates them onto the model open boundary points. Supports multiple models and SSP experiments in one run.

Command Purpose
check-cmip6-coverage Query Pangeo/ESGF and report availability
run-cmip6-boundaries Download and interpolate CMIP6 boundary conditions
boundary-diagnostics QC plots and report for the output files

Requires the [cmip6] extra (and [xesmf] for tripolar models):

pip install -e ".[cmip6,xesmf]"

Config structure

# config/cmip6_mymodel_bdy_create.yaml

source_type: cmip6

setup:
  name: mymodel_cmip6

boundary_points:
  file_path: "./bdy_coords/mymodel_bdy_lonlat.txt"

time_range:
  start_date: "2015-01-01"
  end_date:   "2100-12-31"

cmip6:
  prefer: http              # http (download) or opendap (stream)
  esgf_cache_dir: "/data/cache/cmip6"
  download_workers: 4

output:
  base_directory: "./boundary_data/mymodel_cmip6"

# Models and experiments to process — all combinations are run
models:
  - source_id: MPI-ESM1-2-HR
    experiments:
      - experiment_id: historical
      - experiment_id: ssp126
      - experiment_id: ssp370

datasets:
  temperature:
    category: physics
    cmip6_variable: thetao
    table_id: Omon
    variables:
      - name: thetao
    depth_range:
      minimum: 0.0
      maximum: 5000.0
  salinity:
    category: physics
    cmip6_variable: so
    table_id: Omon
    variables:
      - name: so
    depth_range:
      minimum: 0.0
      maximum: 5000.0

Output is written per model × experiment:

boundary_data/mymodel_cmip6/MPI-ESM1-2-HR/historical/temperature_…nc
boundary_data/mymodel_cmip6/MPI-ESM1-2-HR/ssp126/temperature_….nc

Workflow

1. Check availability

check-cmip6-coverage --config config/cmip6_mymodel_bdy_create.yaml
check-cmip6-coverage --config config/cmip6_mymodel_bdy_create.yaml --model MPI-ESM1-2-HR
check-cmip6-coverage --config config/cmip6_mymodel_bdy_create.yaml --category physics
check-cmip6-coverage --config config/cmip6_mymodel_bdy_create.yaml --download   # pre-fetch

2. Dry run

run-cmip6-boundaries --config config/cmip6_mymodel_bdy_create.yaml --dryrun

Queries ESGF and prints file names, sizes, and cache status without downloading.

3. Run

run-cmip6-boundaries --config config/cmip6_mymodel_bdy_create.yaml
run-cmip6-boundaries --config config/cmip6_mymodel_bdy_create.yaml --model MPI-ESM1-2-HR
run-cmip6-boundaries --config config/cmip6_mymodel_bdy_create.yaml --experiment ssp126 ssp370
run-cmip6-boundaries --config config/cmip6_mymodel_bdy_create.yaml --category physics
Option Description
--model MODEL … Restrict to these source_id values
--experiment EXP … Restrict to these experiment_id values
--dataset KEY … Restrict to these dataset keys
--category CATEGORY … Filter by category (physics, bio)
--prefer http\|opendap Override download method
--workers N Parallel HTTP download threads
--download-only Cache data, skip interpolation and file writing

4. QC diagnostics

boundary-diagnostics --output-dir ./boundary_data/mymodel_cmip6/MPI-ESM1-2-HR/ssp126 \
                     --config config/cmip6_mymodel_bdy_create.yaml

See boundary-diagnostics.md.
